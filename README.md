## Proyectos

### Gestión de Gastos

Aplicación web personal desarrollada para registrar y administrar ingresos y gastos.

El proyecto cuenta con autenticación de usuarios, operaciones CRUD y diferentes opciones para consultar y filtrar la información almacenada.

Fue desarrollado utilizando una arquitectura MVC, separando la lógica de negocio, el acceso a los datos y la presentación.

**Tecnologías utilizadas**

- PHP
- MySQL
- JavaScript
- HTML
- CSS
- MVC

[Ver repositorio](https://github.com/julidann/gestion-gastos)

### Tienda de dispositivos Apple

Proyecto desarrollado inicialmente como una aplicación web para administrar un catálogo de productos y posteriormente ampliado mediante una API REST.

La aplicación permite administrar productos y categorías y realizar las operaciones necesarias para mantener el catálogo.

El proyecto me permitió trabajar tanto con una arquitectura MVC tradicional como con una arquitectura basada en servicios REST.
